# Python-Learning 🐍

我是大一学生，正在从零学习编程与 GitHub。这个仓库记录我的 Python 学习全过程。

## 🎯 学习目标
- 掌握 Python 基础语法与思维方式
- 能独立写小项目（脚本 / 小游戏 / 数据处理）
- 为 AI、自动化、数据处理打基础

## 📁 目录结构
```
Python-Learning/
├── README.md
├── .gitignore
├── notes/          # 学习笔记（复制 templates/learning-note.md 来写）
├── projects/       # 练手小项目
├── assignments/    # 课程作业
└── templates/      # Markdown 模板
```

## 🚀 日常流程
1. 在 `notes/` 里复制 `templates/learning-note.md` 写笔记
2. 在 `projects/` 放自己的小项目
3. 每次学习后用 Git 提交：
```bash
git add .
git commit -m "学习：函数与递归"
git push
```
